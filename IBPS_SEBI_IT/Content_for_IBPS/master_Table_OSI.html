🔌 Network Devices Quick Reference

Hub (Layer 1):

Broadcasts data to ALL ports. No intelligence. Causes collisions. Obsolete.

Switch (Layer 2):

Forwards data only to destination port using MAC addresses. Creates separate collision domains.

Router (Layer 3):

Routes packets between different networks using IP addresses. Connects LANs to WANs.

Brouter (Layer 2 & 3):

Bridge + Router. Routes routable protocols, bridges non-routable protocols.

Modem (Layer 1):

Modulator-Demodulator. Converts digital to analog and vice versa for transmission over phone lines.

Gateway (Layer 7):

Protocol converter. Connects networks with different protocols. Works at all layers.

Firewall (Layer 3-7):

Filters traffic based on rules. Can operate at multiple layers (packet filtering to application layer).

IPsec, VPNs, ACLs, Firewalls, IP spoofing prevention, NAT

Physical access control, Cable security, Fiber optics, EMI shielding
